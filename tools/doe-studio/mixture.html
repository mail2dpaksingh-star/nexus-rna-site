1 · Set constrained molar composition

All four components sum to exactly 100 mol%. The bounds describe a feasible region, not independent lipid-factor ranges.

Process factors

Process factors are independent of lipid composition and use low, center and high coded levels. Disable a process factor to fit a mixture-only model.

2 · Scientific DOE checklist

  • Composition: four mole fractions form a simplex; the generated settings also respect user-specified lower/upper limits.
  • Design candidate set: constrained polytope vertices plus interior interpolations; rank-first/space-filling selection. This is not a certified D-optimal design.
  • Regression: Scheffé mixture components and pairwise terms with lipid–process interactions. No independent intercept, avoiding collinearity with the 100% constraint.
  • Replication: repeated measurement of one batch is not an independent formulation replicate. Design independent batches and track biological unit and time/lot as separate covariates.
  • QC mapping: the QC Studio must use the DOE run ID (such as MP001) as its sample ID to transfer matching results.
  • Evidence: fitted correlations are hypotheses. Validate on new batches and compare against pre-defined CQAs.
