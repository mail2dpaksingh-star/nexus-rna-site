Explicit source → registered sample mapping

All source sample IDs must map to a pre-registered sample. Unmapped source IDs block the entire import. Excluded or nonquantifiable values are reported rather than treated as zero.

Matched Experimental Construct Comparisons

Compare construct candidates only within identical experiment, cell model, batch, condition, time point, analyte, assay, unit and normalization. Technical repeats are first collapsed within each biological replicate; Cq differences are never presented as gene-expression fold changes.
