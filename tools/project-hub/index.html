Project identity and persistence

Local browser storage is not audited, encrypted, backed up, or equivalent to LIMS, electronic laboratory notebooks or 21 CFR Part 11 controls. Do not store patient information or confidential clinical data. Export the project before clearing browser data.

Optional private cloud backup

The Project Hub continues to save analyses to this browser only. When NEXUS account services are configured, you can sign in to save a selected project's research JSON to your private cloud workspace. Cloud syncing is manual—your sequences are not automatically uploaded.
