4. Reproducible benchmark generation

For a validated comparative study, use a separately installed ViennaRNA RNAfold executable and record its version, parameters and input sequences. The bundled offline generator uses a deterministic 125-case synthetic challenge set (the website analyzes at most 50 cases per upload). It creates external reference JSON that this page can import. It does not include or download ViennaRNA.

Recommended first comparison: 37°C, GU enabled, -d0, --noPS (the generator records its exact options). These settings reduce some model differences but do not match the incomplete NEXUS energy model. Include GU-rich, bulged and multibranch-rich cases in later tests to expose limitations.
