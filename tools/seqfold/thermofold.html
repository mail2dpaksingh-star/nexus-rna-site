Method boundaries

  • Turner 2004 NNDB rounded AU/GC/GU stacking + selected hairpin initiation and sequence corrections at 37°C
  • Simplified bulge/internal-loop penalties; affine multibranch terms are provisional
  • Independent external helices and enclosed multibranch structures can be represented
  • No pseudoknots, complete parameter tables by default, multibranch dangles or coaxial stacking; ensemble calculations remain available separately
  • Independent benchmarking against RNAfold and RNAstructure is required before paid scientific use

Scientific methods, references & upgrade roadmap

Calculations use an independently written pseudoknot-free MFE dynamic programming with 37°C rounded AU/GC/GU stacking constants and a documented set of partial nonstacking penalties. The tool does not contain ViennaRNA code or parameter files. Read the v0.5 scientific verification and external-benchmark guide.

Reference sources: RNA Nearest Neighbor Database · Watson–Crick stacking table · Hairpin initiation table · GU stacking table · ViennaRNA licensing.

Next scientific gates: verified complete 1×1/1×2/2×2 table import, remaining special hairpins, multibranch dangle/coaxial terms → independently executed version-matched RNAfold/RNAstructure benchmarks → ensemble calculations → full-length RNA performance.
