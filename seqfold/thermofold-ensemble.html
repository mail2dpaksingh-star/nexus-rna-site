How to interpret these predictions

Unlike a single minimum-free-energy structure, an ensemble describes alternative folds and gives each a Boltzmann weight. Probabilities come from a native NEXUS dynamic-programming inside/outside calculation rather than using ViennaRNA code. The current parameterization is incomplete, so meaningful agreement with experimental data or full thermodynamic references is still an open validation gate.

Scientific basis: McCaskill's partition-function formulation; published energy parameters: Turner nearest-neighbor database. Read the methods and validation report.
